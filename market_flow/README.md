# 한국 증시 수급·옵션 데일리 브리프 (4주 파일럿)

운영 기간: 2026-11-05 ~ 2026-12-03 (KST, 거래일만)

## 현재 상태

**분석 PDF의 정기 생성과 전송은 보류한다.** 현재 확보한 당일 수급·종가·옵션 총민감도로 만든 규칙형 문장은 관측값을 재서술하는 수준이다. 고점·저점 또는 포지션을 잡은 이유를 판단할 근거가 부족하므로, 이 결과물을 데일리 브리핑으로 운영하지 않는다. 기존 PDF 코드는 서식과 데이터 검증용 실험물로만 둔다. 현재 예약 실행은 없다.

당분간 KRX/KIS 수집 결과의 날짜·단위·정규장 계약 검증만 유지한다. 분석 리포트 재개 전에는 (1) KOSPI200·KOSDAQ150의 투자자별 선물 수급, (2) 행사가별 옵션 미결제약정과 내재변동성의 전일 대비 변화, (3) 충분한 거래일 비교 기준과 지수 구성종목 기여도, (4) 관측 신호와 반증 조건을 연결하는 분석 설계를 확보·검증한다. 외국인의 거래 동기와 딜러 순감마는 공개 집계치만으로 확정하지 않는다.

## 범위와 시간

- 현물: KOSPI, KOSDAQ의 지수 종가·투자자별 순매수·프로그램 차익/비차익 순매수
- 파생: KOSPI200, KOSDAQ150의 주간 선물·월물/위클리 옵션 종가와 미결제약정
- 기준: 현물 15:30, 파생상품 통상 15:45 종료. 만기일에는 해당 계약의 최종거래 시각을 따로 확인
- 실행 권장: 거래일 16:20 KST 이후. 종가 데이터와 투자자별 수급의 공개 시차가 있으면 실제 자료 확인 뒤 실행
- 결과: A4 최대 2쪽 PDF. 데이터 날짜·출처·조회 시각을 명기

## 분석 원칙

1. 당일 순매수는 **포지션 잔고가 아닌 거래 흐름**으로 표기한다.
2. 옵션 미결제약정과 그릭만 있으면 행사가별 **총 감마/델타 민감도 규모**만 추정한다. 보유자의 매수·매도 방향이 없으므로 시장 순감마·순델타나 딜러 헤지 방향을 단정하지 않는다.
3. 변곡점은 예측치가 아니라 **경계 신호**로 표기한다. 현물 가격과 외국인 선물, 프로그램 흐름이 어긋나는지 확인하고 반증 조건을 함께 적는다.
4. '왜 포지션을 잡았는지'는 관측 데이터에서 가능한 설명을 **가설**로 적고, 확인되지 않은 동기나 인과를 사실로 표현하지 않는다.
5. PDF 첫 장은 숫자 나열보다 **가격과 수급의 동행·괴리**, 가능한 설명, 다음 거래일의 가설 강화·약화 조건을 우선 제시한다. 조건은 당일 종가와 수급 방향을 기준으로 한 관찰 기준이며 목표가나 매매 신호가 아니다.
6. 프로그램 차익·비차익 합계는 프로그램 안에서만 계산한다. 투자자별 수급과 프로그램 수급은 분류 축이 다르므로 두 값을 더해 전체 순매수로 해석하지 않는다.
7. 옵션 감마는 총량과 기초지수에서의 행사가 거리로 **관찰 구간**을 표시한다. 매수·매도 포지션 부호가 없으므로 지지·저항, 딜러 헤지 방향, 고점·저점을 단정하지 않는다.
8. 수집기는 출력 폴더의 이전 실측 JSON을 최대 4거래일 읽어 당일 자료에 붙인다. PDF는 최대 5거래일 지수 수익률·외국인/프로그램 누적 흐름과 당일 괴리를 대조한다. 이전 자료가 없으면 지속성을 판별할 수 없다고 적는다. 가상 데이터는 이 이력에 포함하지 않는다.

## 입력

매일 `data/YYYY-MM-DD.json`을 `example_input.json` 형식으로 채운다. 각 출처의 `asof_kst`는 해당 거래일 주간장 종료 이후 실제 조회 시각으로 설정한다. 다음 날 재조회했으면 다음 날 시각을 그대로 기록한다. 옵션 그릭은 같은 기초지수·같은 장마감 스냅샷이어야 한다. JSON의 `demo`가 `true`면 PDF 시험 생성은 가능하나 텔레그램 발송은 금지된다.

`collect.py`는 KRX 지수 종가와 KIS 투자자별 현물 순매수·프로그램 차익/비차익 순매수를 자동 수집한다. 거래일·자료 날짜를 확인하고 KRX/KIS 종가를 대조한다. `collect_derivatives.py`는 승인된 KRX API에서 정규 KOSPI200·KOSDAQ150 선물과 월물·위클리 옵션을 골라 한 거래일 입력에 합친다. 옵션 델타·감마는 KRX 종가·내재변동성으로 계산한 무배당·무이자 Black-Scholes **근사치**이며, 보유 주체별 순포지션이 아니다. 외국인 선물 순매수는 현재 API에 없으므로 `null`로 남긴다. 이때 PDF는 **검토본**으로 생성되며 누락과 해석 제한을 명시한다. `--send`는 자료가 채워지기 전까지 실패한다.

2026-11-05 추가 승인 후 기존 `KRX_API_KEY`로 `drv/fut_bydd_trd`, `drv/opt_bydd_trd` 호출에 성공했다. 2026-11-04 데이터에서 정규·야간 선물 종가 및 옵션 종가·내재변동성·미결제약정을 확인했다. 해당 Open API에는 투자자별 선물 순매수 필드가 없어 별도 자료 경로가 필요하다. 따라서 **자동 발송 예약 작업은 아직 활성화하지 않았다.**

외국인 선물 거래 흐름의 표본 파일을 받으려면 [KRX 투자자별 거래실적](https://data.krx.co.kr/contents/MDC/MDI/mdiLoader/index.cmd?menuId=MDC0201050302)에 Data Marketplace 계정으로 로그인한다. 메뉴 경로는 `통계 → 기본 통계 → 파생상품 → 거래실적 → 투자자별 거래실적`이다. 로그아웃 상태에서 해당 메뉴를 누르거나 직접 주소를 열면 로그인 화면으로 이동한다. 로그인 후 KOSPI200 선물과 KOSDAQ150 선물의 **같은 거래일 정규장** 조회 결과를 CSV/엑셀로 한 번씩 내려받아 필드와 단위를 확인한다. 화면 파일은 표본 매핑용이며, 매일 자동화하려면 별도 이용 가능한 데이터 공급 경로가 필요하다.

KRX Data Marketplace의 [선물 데이터 상품 목록](https://data.krx.co.kr/contents/MDC/DATA/datasale/index.cmd?prodType=FF&viewNm=dataProdList)에는 선물 **투자자별 거래실적**이 별도 항목으로 안내된다. 사용 권한, 제공 시간, 자동 수신 방식은 계약 조건을 확인해야 한다. 현재 KRX Open API 선물 일별매매정보 호출 승인만으로 이 데이터가 제공되는 것은 아니다.

## 실행

```powershell
$python = 'C:\Users\PC\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $python .\collect.py --date 2026-11-05 --output .\data\2026-11-05.json
& $python .\daily_brief.py --input .\data\2026-11-05.json --output .\reports
```

발송 전에 사용자 환경변수 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 설정하고 봇을 본인만 접근하는 비공개 수신처에 추가한다. `MARKET_FLOW_PRIVATE_RECIPIENT=1`을 명시한 경우에만 `--send`를 사용할 수 있으며 `@채널명` 주소는 차단한다. 같은 날짜/같은 PDF의 중복 발송은 발송 영수증 파일로 막는다.

`@biyosi77`은 공개채널이다. KRX Open API 약관 제11조는 제공 정보를 제3자에게 제공하는 것을 제한하며, KIS Open API 안내는 개인 고객의 시세정보를 본인 투자 목적에만 사용하고 제3자 제공을 금지한다. 현재 API 키로 만든 데이터 PDF를 그 공개채널에 게시하는 경로는 활성화하지 않는다. 별도 재배포 권한이 확인되면 발송 경로를 재검토한다.

사용자는 재배포 권한을 확인한 뒤 공개채널을 운영하기로 했다. KRX 선물·옵션 API 호출 권한은 데이터 재배포 허가와 별개이므로 두 사항을 각각 확인해야 한다. 현재 `--send`는 비공개 수신처 전용 보호 장치이며, 공개채널 전송은 권한 확인 후 별도 변경이 필요하다.

데이터가 누락되거나 시각이 맞지 않으면 프로그램은 실패하고 PDF를 전송하지 않는다. PC가 꺼져 있으면 로컬 예약 실행도 작동하지 않는다.
